01 / Mathematical background

FINITE FIELD

For a prime modulus p, the points of an elliptic curve satisfy y² ≡ x³ + ax + b (mod p), together with the point at infinity O. This exercise uses the nonsingular curve below and the valid generator G = (1, 5).

E: y² ≡ x³ + 7 (mod 17)   ·   G = (1, 5)   ·   Q = kG

Adding two different points

λ = (y₂ − y₁) · (x₂ − x₁)⁻¹ mod p

Doubling a point

λ = (3x₁² + a) · (2y₁)⁻¹ mod p
x₃ = λ² − x₁ − x₂   ;   y₃ = λ(x₁ − x₃) − y₁   (mod p)

All divisions above mean multiplication by a modular inverse. O is the identity element; adding a point and its opposite returns O. The point G has order 9, so distinct nonzero multiples are obtained for k = 1,…,8. This is a teaching curve, not a secure cryptosystem.

04 / The JavaScript algorithm

NO CRYPTO LIBRARIES

Repeated addition

let result = null; // O: point at infinity
for (let i = 0; i < k; i++) {
  result = addPoints(result, G);
}

Time complexity: O(k) point additions. For educational visualization and small keys.

Double-and-add

let result = null, addend = G;
while (k > 0) {
  if (k % 2 === 1) result = addPoints(result, addend);
  addend = addPoints(addend, addend);
  k = Math.floor(k / 2);
}

Time complexity: O(log k) group operations. Both procedures must return the same point.

05 / Statistical exploration

EXHAUSTIVE · ORDER 9

Enumerate all eight valid private scalars for the subgroup generated by G, then count the x/y coordinates of Q = kG. The sample space is small enough to inspect completely.

06 / Interpreting the statistics

A cryptographic one-way function is defined by the computational difficulty of finding a preimage, not by an output histogram that merely looks random.
  • Distribution and frequencies: measurable properties of sampled points; they depend on the curve, subgroup and key distribution.
  • Bit patterns and correlations: useful diagnostics, but no small-sample statistical test establishes ECDLP hardness.
  • Avalanche effect: a familiar design/testing expectation for hashes; nearby scalars on a toy curve do not have to show a hash-like avalanche property.
  • Collisions: k and k+9 produce the same Q here because G has order 9. Real-world keys must respect the subgroup order.

For a full-order generator of a large prime-order group, uniformly sampled nonzero scalars produce uniformly distributed non-identity group elements. Coordinate values themselves need not be uniformly distributed over the field.

Conclusion

The map k ↦ kG is easy to evaluate using group operations. On this toy curve it is equally easy to invert by exhaustive search. The exercise illustrates the mechanism of public-key generation, while the security of real elliptic-curve systems relies on much larger groups and the computational hardness of the discrete logarithm problem—not on superficial randomness in plotted coordinates.
