01 / THE MATHEMATICS

From Knuth to Welford

We update the statistics without storing or reprocessing all past observations.

STEP 01x̄

Incremental mean (Knuth)

After observing n − 1 values, let the previous mean be x̄n−1. Add a new observation xn:

x̄n = [(n − 1)x̄n−1 + xn] / n

Rearranging gives the online update:

δn = xn − x̄n−1
x̄n = x̄n−1 + δn / n
STEP 02Σ

Sum of squared deviations

Define SSn = Σi=1n(xi − x̄n)². Since the deviations around the old mean sum to zero, expanding the squares yields:

SSn = SSn−1 + (n − 1)(x̄n − x̄n−1)²
+ (xn − x̄n)²

Using x̄n − x̄n−1 = δn/n, simplify to Welford's recurrence:

SSn = SSn−1 + δn(xn − x̄n)
STEP 03s²

Sample variance

For n ≥ 2, the unbiased sample variance divides the sum of squared deviations by n − 1:

s²n = SSn / (n − 1)

Because SSn−1 = (n − 2)s²n−1, an equivalent direct recurrence is:

s²n = [(n − 2)s²n−1 + δn(xn − x̄n)] / (n − 1)

At n = 1, sample variance is undefined. Population variance, by contrast, is SSn / n.

✦

Why does it work? The mean shifts when a new observation arrives, so old squared deviations must be adjusted. Welford's identity accounts for that shift in one update, avoiding repeated sums and reducing numerical cancellation.

02 / IMPLEMENTATION

Three lines. One pass.

The core update requires just three statements after incrementing the count.

welford.js
// State: count = 0, mean = 0, M2 = 0
function update(x) {
  count++;
  const delta = x - mean;
  mean += delta / count;
  M2 += delta * (x - mean);
}

// Sample variance: n must be at least 2
const variance = count > 1 ? M2 / (count - 1) : NaN;
01

Constant memory

Only count, mean, and M2 are maintained, regardless of the dataset size.

02

Numerical stability

Avoids computing variance as Σx²/n − μ², which may lose precision for large values with small deviations.

03

Streaming friendly

Process each observation as soon as it arrives. No second pass is required.

04 / TAKEAWAYS

Conclusions

What the formulas establish, and why they are useful in statistics.

↗

Efficient sequential updates

The mean and sum of squared deviations can be updated immediately after each observation with constant additional storage and linear total processing time.

≋

More robust computation

Welford's recurrence avoids the numerically fragile difference of two large terms in the one-pass formula based on Σx² and (Σx)².

◎

Foundation for inference

The sample variance, s² = SS/(n − 1), is an unbiased estimator of population variance for independent, identically distributed observations with finite variance.

Important distinction: Sample variance is undefined for one observation; population variance uses n rather than n − 1. In the next exercise, repeated samples can be compared with a known theoretical mean and variance.
