01 / PROBABILITY MODEL

One fixed distribution

Each attempt produces an independent integer score between 0 and 10. All hackers draw from the same distribution.

STEP 01P(X)

Score probabilities

We choose the following discrete, non-uniform probability mass function. All six probabilities sum to 1.

Score xP(X = x)

A score represents performance on one penetration attempt; the experiment models the scores, not actual network activity.

STEP 02μ

Theoretical mean

For this population distribution, the expected score is

μ = E[X] = Σx x · P(X = x)
μ = 5.8

It is a fixed population parameter, not a value estimated from the simulated hackers.

STEP 03σ²

Theoretical variance

The population variance quantifies the dispersion of individual attempt scores.

σ² = E[X²] − μ²
= Σx x²P(X = x) − μ²
σ² = 6.76

Each hacker's sample variance is estimated using the denominator n − 1.

✦

Experiment design. We generate m independent trajectories, each with n independent scores drawn with replacement from the displayed distribution. We use a seeded pseudo-random number generator so the experiment can be reproduced.

02 / IMPLEMENTATION

Welford for every hacker

The three-line update from Exercise 1 is applied separately to each trajectory.

sampling.js · core logic
// One independent trajectory per hacker
function welford(scores) {
  let n = 0, mean = 0, M2 = 0;
  for (const x of scores) {
    n++;
    const delta = x - mean;
    mean += delta / n;
    M2 += delta * (x - mean);
  }
  return {
    mean,
    variance: n > 1 ? M2 / (n - 1) : NaN
  };
}

05 / INFERENTIAL STATISTICS

Conclusions

How sampling connects the observed trajectories to population parameters.

≈

Unbiased estimators

For independent, identically distributed scores, E[x̄] = μ and E[s²] = σ². Averages across many hackers therefore tend to approach the theoretical values as m grows, even when n is small (provided n ≥ 2).

↘

Reduced sampling variability

The variance of a sample mean is σ²/n, so its standard deviation is σ/√n. Increasing n makes sample means more concentrated. Sample variances also become more stable as n increases for this bounded distribution.

◎

Why inference needs this

Sampling distributions quantify uncertainty. They motivate standard errors, confidence intervals, hypothesis testing, and the law of large numbers. With larger n, estimates from individual hackers become more precise.

Interpretation matters: Increasing n reduces the dispersion of individual hackers' estimators. Increasing m mainly improves how accurately the simulation estimates the averages and spreads of those estimators. The sample variance uses n − 1, not n, to avoid systematic downward bias.
