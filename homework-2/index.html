01 / ECC encryption & decryption

LIVE COMPUTATION

Use the secp256k1 curve y² = x³ + 7 (mod p). The receiver's private key is k and public point Q = kG. The sender selects ephemeral r, publishes R = rG and derives S = rQ. The receiver obtains the same point with S = kR. A Keccak-256-derived byte stream masks the message with XOR.

Q = kG · R = rG · S = rQ = kR · ciphertext = UTF8(message) XOR K(S)

02 / Caesar cipher

26 POSSIBLE SHIFTS

A symmetric substitution maps each Latin letter to a letter k positions later; spaces and punctuation remain unchanged. Encryption is deterministic and preserves letter frequencies up to a cyclic permutation.

Eₖ(x) = (x + k) mod 26   ·   Dₖ(y) = (y − k) mod 26

04 / Statistical cryptanalysis of Caesar

χ² LETTER FREQUENCY

The ciphertext is scored against known English letter probabilities for all 26 possible inverse shifts. The best match minimizes Pearson's chi-squared statistic, χ² = Σ (observed − expected)² / expected. Frequency analysis is unreliable on short or non-English messages.

05 / Sample size & attack success

REPRODUCIBLE MONTE CARLO

Draw contiguous English-language excerpts of each length from an embedded study corpus, encrypt each with a uniformly selected Caesar shift, recover the shift via χ² and record how often it matches the real key. The fixed seed reproduces results. Excerpts come from a small embedded corpus, so the experiment illustrates the method rather than proving general performance on all English texts.

LettersRecoveredTrialsSuccess rate

The law of large numbers improves the stability of estimated letter frequencies as text length grows, but individual outcomes are not guaranteed to improve monotonically.

06 / Restricted ECC private-key attack

EXHAUSTIVE SEARCH

The attacker knows the public key Q = kG but not the private key. Since this teaching model restricts k to 1–4096, the attacker checks G, 2G, 3G, … until one matches Q. It does not inspect the message, language, or ciphertext frequencies.

At full secp256k1 key sizes, exhaustive enumeration is not practically feasible. A matching public point in this demo proves only that an intentionally small search space is weak.

07 / Discussion & conclusions

Caesar: statistical leakage

Fixed substitution preserves the shape of English letter frequencies, shifted around the alphabet. With enough ciphertext, χ² can identify the most plausible shift. With very short text, atypical vocabulary or an incorrect language model, statistical recovery may fail. Exhaustive search of all 26 shifts always lists the correct candidate but does not automatically identify it.

ECC: insufficient key entropy

The demonstration uses the real secp256k1 group but a weak distribution for private keys. Brute force exploits the tiny number of candidates, not any detectable plaintext frequencies. A large key space is necessary but not sufficient: implementations also need vetted encryption modes, secure randomness, side-channel protections and proper point validation.
