01 / Definitions & mathematics

TWO DIFFERENT PARTITIONS

Riemann: partition the domain

Rₙ = Σ f(tᵢ) Δxᵢ

Choose tags at the left endpoint, midpoint or right endpoint of each subinterval. Every rectangle uses a width Δx.

Lebesgue: partition the range

Lₙ = m(b−a) + h Σ μ{x : f(x) ≥ m+kh}

For nonnegative measurable functions, use lower-level simple functions. The implementation computes measures of superlevel sets, not a relabelled Riemann grid.

Lebesgue sums use analytically determined superlevel measures where available. The unbounded 1/√x example uses a growing truncation threshold, whose omitted tail is explicitly reported. Numerical sampling of the input domain would otherwise introduce a second, separate approximation error.

04 / Pathological examples

MATHEMATICAL LIMITATIONS

Dirichlet function

f(x) = 1 if x ∈ ℚ, otherwise 0

Every subinterval contains rationals and irrationals. Lower Darboux sums remain 0 and upper sums remain 1: not Riemann-integrable. The rationals have Lebesgue measure zero, so its Lebesgue integral is 0.

Thomae function

f(p/q) = 1/q (reduced), f(irrational) = 0

Continuous at irrationals, discontinuous at rationals. Its discontinuity set is null: it is Riemann- and Lebesgue-integrable, both integrals equal 0.

A floating-point number in JavaScript is rational. Evaluating the Dirichlet function directly at floating-point tags would return 1 everywhere and misleadingly suggest an integral of 1. The following demonstration uses mathematical tags and upper/lower sums, not floating-point classification.

05 / Standard normal CDF

EXERCISE 2

The standard normal distribution function is an integral of the Gaussian density. Its indefinite integral has no expression using only elementary functions. Liouville's theorem on elementary antiderivatives explains the obstruction; the special function erf gives an exact mathematical representation, not an elementary one.

Φ(z) = ∫₋∞ᶻ exp(−t²/2)/√(2π) dt = ½[1 + erf(z/√2)]
—Against high-precision reference
—Centred around z = 0

—Published numerical value or high-precision constant
Standard normal density · shaded cumulative probability
For large positive z, Φ(z) is close to 1 and absolute error alone can hide a poor estimate of the upper-tail probability 1 − Φ(z). The Taylor series is best near zero and may suffer cancellation in the tails. Use Simpson or a tailored tail approximation when high relative tail accuracy is required.

07 / Discussion & conclusions

STATISTICAL INTERPRETATION

Integration

For Riemann-integrable functions, correctly constructed domain and range approximations converge to the same integral. Smooth functions reward midpoint quadrature; step functions favour exact value-level partitions. For non-Riemann-integrable but measurable functions, Lebesgue integration can still exist.

Normal CDF

The Gaussian CDF has an exact special-function representation, yet accurate probability calculations need numerical algorithms. Simpson quadrature offers transparent convergence; the series performs well near the origin; a short erf approximation is fast with limited precision.

The estimated costs and errors refer to mathematical/numerical algorithms, not real-world security penetration rates. All computations run locally in the browser; no external JavaScript libraries are needed.
